# Support

LinkJig is made by one developer. Every message is read; please allow a few days for an answer.

- **Bug reports and feature requests:** [Issues](../../issues/new/choose). Issues are reviewed weekly.
- **Questions and ideas:** [Discussions](../../discussions)
- **E-mail:** linkjig.app@gmail.com
- **From the app:** Settings → Send feedback opens your e-mail app with a diagnostic report
  (app version, OS, permissions, link type). It contains no terminal data and no personal data.

Before reporting a connection problem, please check the [FAQ](https://linkjig.github.io/faq.html).
