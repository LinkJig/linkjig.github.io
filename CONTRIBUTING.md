# Contributing

Thank you for helping. The app code is closed, so code contributions are not accepted. These are very
welcome:

- **Bug reports:** use the bug template and add the diagnostic report (Settings → Send feedback).
- **Scenario packs** for the library: use the pack template. Only share what you wrote yourself, with no
  content from your employer or anyone else's protected material, and say which hardware you tested it on.
  Packs are shared under CC BY 4.0.
- **Translations:** corrections to the English, Turkish, German, Spanish or Portuguese texts.
- **Documentation:** fixes to the FAQ or this repository's documents.
