Faça um módulo ESP transmitir a própria rede Wi-Fi, pelo celular

Um ESP8266 com firmware AT pode criar a própria rede Wi-Fi, para que um celular ou computador entre nela sem roteador. São sete comandos AT na ordem certa. O LinkJig envia todos por você e confere cada resposta.

Esta é uma sessão real: um ESP-01S com firmware AT 2.2.0, ligado a um celular Android por USB OTG e um adaptador USB-UART CH340.

Crie a rede

  1. Conecte o adaptador e abra o seu dispositivo serial.
  2. Abra a aba Módulos, escolha ESP8266 e depois Criar uma rede Wi-Fi.
  3. Digite um nome de rede e uma senha com pelo menos 8 caracteres. Canal 6 e WPA2 são o padrão.
  4. Toque em Criar rede.

Cada passo é conferido antes de o próximo ser enviado. A senha nunca aparece na tela; ela é mostrada como asteriscos.

Os sete comandos

19:54:42.563 TX AT
19:54:42.616 RX AT
OK
19:54:42.627 TX AT+SYSSTORE=0
19:54:42.648 RX AT+SYSSTORE=0
OK
19:54:42.670 TX AT+CWMODE=2
19:54:42.696 RX AT+CWMODE=2
OK
19:54:42.721 TX AT+CWSAP="ESP-bench","***",6,3
ComandoO que faz
ATConfere se o módulo responde
AT+SYSSTORE=0Não grava as próximas configurações na flash
AT+CWMODE=2Muda para o modo ponto de acesso
AT+CWSAP="nome","senha",6,3Inicia a rede: nome, senha, canal, segurança (3 = WPA2)
AT+CWSAP?Lê a rede de volta
AT+CIPAP?Lê o endereço do próprio módulo
AT+SYSSTORE=1Restaura o padrão

O módulo respondeu com o endereço:

+CIPAP:ip:"192.168.42.1"
+CIPAP:gateway:"192.168.42.1"
+CIPAP:netmask:"255.255.255.0"
OK

Cada comando e resposta também fica no terminal, então você vê exatamente o que foi enviado.

Limites

  • Nesta sessão Manter após reiniciar estava desligado: a rede some quando o módulo reinicia. Ligue para gravar na flash.
  • Gravado com firmware AT 2.2.0. Outras versões de AT podem responder de outro jeito.
  • O endereço de fábrica de uma rede ESP8266 costuma ser 192.168.4.1. Este módulo tinha sido configurado para 192.168.42.1 antes da gravação.
  • Testado ao vivo com um adaptador CH340 no Android 9.
